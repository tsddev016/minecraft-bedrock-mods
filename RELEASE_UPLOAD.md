# Como subir os packs no GitHub Releases

1. Abra https://github.com/tsddev016/minecraft-bedrock-mods/releases/new
2. Tag: `v1.0`
3. Título: `Mods Bedrock v1.0 — versões atuais`
4. Anexe estes arquivos (da pasta local de desenvolvimento):
   - MedidorEnergia_v1.3.mcaddon
   - PCGamer_v1.3.2.mcaddon
   - GridCarvao_1.0.1.mcaddon
   - CineOS_Mobile_1.1.mcaddon
   - VozProximidade_BP_v1.0.3.mcpack
   - Televisao_v1.0.mcaddon
   - GuiaDosMods.mcaddon
   - voz-minecraft-completo.zip
5. Publish release
